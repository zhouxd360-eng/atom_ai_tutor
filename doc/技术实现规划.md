# 家庭导师 Agent 落地全路径规划

（多模态学生知识库 + 个性化学情 + 成长规划）

整体分**需求拆解→数据层建设→知识库架构→Agent大模型应用层→功能模块迭代→部署落地**6大阶段，从轻原型到正式可用分3期落地，优先低成本验证核心能力，再逐步补全多模态与成长规划。

---

## 一、整体产品定位

**家庭专属AI家教Agent**：以学生个人私有知识库为核心，融合课本、习题、测验、音视频、性格、日常行为数据，实现：

- 学情诊断 → 自适应出题 → 个性化学习规划 → 习惯矫正 → 劳逸结合排课 → 随机语音抽查

区别通用AI，所有内容绑定孩子专属档案，不依赖通用知识库。

---

## 二、阶段1：需求与数据源梳理（1~2周，前期准备）

### 1. 分类梳理全量多模态数据源（构建私有学生库原始素材）

| 数据类型 | 具体内容 | 采集方式 |
|---------|---------|---------|
| **文本类（核心学科）** | 中小学各版本教材电子版、课后习题、单元试卷、错题本、历次考试成绩单、课堂笔记 | PDF/Word导入、拍照OCR、手动录入错题 |
| **测验数据** | 周测/月考得分、错题知识点、失分原因、薄弱题型 | 表格批量导入、AI试卷识别 |
| **视频数据** | 课堂网课、知识点讲解视频、孩子上课录屏、居家学习实拍片段 | 本地视频上传、短视频提取文本+关键帧 |
| **语音数据** | 随机口语抽查录音、背书录音、答疑语音、日常闲聊语音（学习习惯相关） | 手机APP/小程序实时录音，语音转文字 |
| **行为&性格数据** | 作息、专注力、厌学科目、好动/内向/粗心等性格标签、作息记录、作息偷懒记录、课外兴趣、作息作息碎片 | 家长手动标签+AI从日常片段自动提取 |
| **成长规划文本** | 年级培养目标、升学节点、家长预期、课外拓展计划（体育/艺术） | 自定义文档录入 |

### 2. 拆分核心业务能力清单（分优先级）

- **P0（一期必做）**：知识点学情诊断、错题建档、自适应出题
- **P1（二期）**：多模态数据入库、语音随机抽查、学习排课、劳逸结合日程规划
- **P2（三期）**：性格驱动成长路径定制、坏习惯自动识别纠正、长期成长规划

---

## 三、阶段2：底层数据&知识库搭建（2~4周，技术底座）

### 1. 多模态预处理流水线

#### 文本预处理
教材/试卷OCR→文本清洗→知识点切片标注（绑定课标知识点ID，如：小学数学-三年级-四则混合运算），建立【知识点-章节-年级-教材版本】四层标签体系。

#### 音视频预处理
- **语音**：ASR转文字→文本语义提取（是否知识点掌握、口语错误、厌学表述），保存音频源文件+文本摘要；
- **视频**：抽关键帧+字幕OCR，按知识点分段归档，提炼学习表现（走神、认真、听不懂等标签）。

#### 结构化数据
考试分数、作息、性格标签存入结构化数据库（MySQL）；非结构化素材（教材原文、音视频文件、日常随笔）存对象存储。

### 2. 双库架构：结构化业务库+向量知识库（RAG核心）

**核心**：每个孩子独立专属向量库，一人一库，隔离数据

#### 结构化数据库（MySQL/PostgreSQL）
存储：学生基础信息、年级、性格标签、历次考试分数、错题索引、学习日程、成长阶段、作息记录、习惯记录（用于数据统计、筛选、报表）。

#### 多模态向量知识库（向量数据库：Chroma/Pinecone/FAISS，本地优先选Chroma）
所有预处理后的教材切片、错题、测验解析、音视频文本摘要、日常学习片段全部向量化入库，每条向量绑定：
- 知识点ID
- 数据类型标签
- 时间标签
- 表现标签

**作用**：Agent提问时，RAG精准召回该学生专属学习数据，不调用通用知识库，只基于孩子自身数据做判断。

### 3. 知识点图谱构建（关键，实现学情定位）

按国家课标搭建学科知识图谱（Neo4j图数据库最优）：
- 节点 = 单个知识点
- 边 = 前置依赖关系（如：先学乘法→再学四则混合运算）

**自动关联**：学生错题/失分数据→锚定图谱知识点，自动标记【已掌握/部分掌握/薄弱/未学】四个掌握度。

## 四、阶段3：Agent大模型应用层开发（分三期迭代，核心逻辑）

**选型建议**：私有部署轻量化大模型（Qwen/Llama3/豆包开源版）+RAG架构，兼顾隐私（孩子学习数据不出本地），不使用第三方云端大模型原始数据；

Agent拆分为5个智能子Agent，分工协作：

### 子Agent1：学情诊断Agent（P0优先开发）
- **输入**：某次测验/作业数据→RAG调取该生历史教材+过往错题+同类习题→遍历知识图谱
- **输出**：全科目知识点掌握报表，薄弱知识点清单、失分根源（概念不懂/粗心/计算失误）。

### 子Agent2：智能出题Agent（P0）
根据薄弱知识点+孩子性格：
- 粗心好动：减少大题量，拆分小题、穿插填空选择；
- 内向畏难：从基础题逐步梯度升难度，少难题；

支持：随堂练习、单元小测、专项错题变式出题，自动生成试卷+答案解析。

### 子Agent3：日程规划Agent（P1）
- **输入**：每日可用学习时长、薄弱知识点、课外兴趣、孩子作息、专注力时段（从日常视频/生活片段提取：早上专注力好/傍晚容易走神）

自动生成每日计划表：
- 学科学习分段+穿插休息、运动、兴趣时间（劳逸结合）；
- 薄弱科目分配更多时段，优势学科减量巩固；
- 周期性微调：周/月根据测验结果自动改计划。

### 子Agent4：语音抽查Agent（P1，多模态落地）
- 定时随机发起语音提问（手机端），围绕当日薄弱知识点口头问答；
- ASR识别孩子回答，存入知识库，更新知识点掌握度；
- 留存语音片段反哺知识库，后续优化出题方向。

### 子Agent5：成长&习惯矫正Agent（P2高阶）
**融合**：长期学情数据+性格标签+日常生活片段（视频/语音）
- **坏习惯识别**：拖延、粗心、厌学某科、注意力涣散，给出针对性矫正方案；
- **中长期成长规划**：学期/学年目标、培优/补差路线、课外拓展建议（理科培优/文科阅读）；
- **动态迭代**：按月根据阶段性测验自动修订成长路径。

## 五、阶段4：分三期落地实施节奏（低成本渐进落地，不用一次性全做完）

### 一期（1个月，最小可用MVP，零门槛落地）
只做文本数据：教材+试卷+错题入库→知识点图谱+RAG→学情诊断+智能出题

**落地形态**：网页/Excel配套小工具，手动导入PDF错题，输入考试成绩自动出学情报告、生成练习题。

成本最低，验证核心逻辑，不需要处理音视频。

### 二期（2~3个月，多模态接入）
新增：语音录音上传、试卷拍照OCR、短视频学习素材入库、日程自动规划、随机语音抽查

**落地形态**：微信小程序/简易APP，手机直接拍照、录音上传数据，自动生成每日学习表。

### 三期（3~4个月，完整家庭导师成品）
全量接入：日常居家视频片段、长期成长规划、性格智能分析、习惯自动纠正，完整闭环。

## 六、阶段5：前端产品形态&部署方案

### 1. 部署方案（家庭私有化优先，保护孩子隐私）
- **本地部署（推荐家用）**：老旧电脑/NAS部署整套服务，知识库、大模型全在本地，所有学习数据不外流；
- **云端轻量化**：小体量部署云服务器（备选，多子女家庭）。

### 2. 前端入口（低成本）
- **首选**：微信小程序（拍照、录音最方便，家长+孩子双端）；
- **备选**：Web网页端，电脑端导入教材文档。

---

## 七、阶段6：迭代优化逻辑（长期持续）
- **数据自迭代**：每次做题、测验、语音抽查、日常记录自动入库，不断丰富学生私有知识库，Agent规划越来越贴合孩子；
- **参数微调（可选高阶）**：积累足量孩子学习数据后，对底座大模型做小样本LoRA微调，适配孩子说话习惯、学习特点；
- **规则自定义**：家长可手动设置约束（每天学习不超2小时、每周2天户外活动、禁止超前超难刷题），Agent规划自动遵循约束。

---

## 八、关键落地避坑建议
1. 先单科目试点（小学数学），跑通全流程再扩展全科，避免一次性全学科投入工作量爆炸；
2. 知识点不要自建，直接对接国标义务教育课标，减少图谱制作成本；
3. 多模态循序渐进，优先文本、再语音、最后视频，视频数据量大、预处理成本最高放到三期；
4. **隐私优先**：所有学生数据本地存储，不上传第三方平台。
