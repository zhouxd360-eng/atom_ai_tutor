# 家庭导师 Agent：学生知识库设计体系

## 一、核心定位

学生知识库不应只是资料库，而应是：

> 学生数字画像 + 学习证据账本 + 成长决策引擎

它需要持续回答三个问题：

1. 孩子会什么？
2. 为什么不会？
3. 下一步应该怎么安排？

---

## 二、总体结构

```text
Student Knowledge Base
├── Student Profile 学生画像层
├── Curriculum Graph 教材知识图谱层
├── Learning Evidence Store 学习证据层
├── Mastery Model 掌握度模型层
├── Misconception & Diagnosis 错因诊断层
├── Growth Planning 成长规划层
└── Agent Action Layer 智能行动层
```

---

## 三、学生画像层

用于理解孩子的基础情况、学习偏好、性格特点和家庭约束。

### 1. 基础信息

| 模块 | 内容 |
|---|---|
| 学生信息 | 年龄、年级、学校、教材版本、地区课标 |
| 学科范围 | 语文、数学、英语、科学等 |
| 当前目标 | 校内提分、竞赛、兴趣拓展、习惯养成、升学准备 |
| 家长期望 | 成绩目标、学习强度、可接受屏幕时间、亲子陪伴方式 |
| 时间资源 | 每日可学习时间、周末时间、兴趣班、休息窗口 |

### 2. 性格与学习风格

| 维度 | 例子 | 对规划的影响 |
|---|---|---|
| 专注稳定性 | 容易走神 / 可长时间沉浸 | 决定学习单元长度 |
| 挫折耐受度 | 错题后逃避 / 愿意重试 | 决定难度爬坡速度 |
| 反馈偏好 | 喜欢表扬 / 喜欢挑战 / 讨厌被纠错 | 决定导师话术 |
| 好奇心方向 | 故事、机械、动植物、竞技等 | 决定题目包装方式 |
| 自主性 | 需要监督 / 可自驱 | 决定计划颗粒度 |
| 表达方式 | 爱说、爱画、爱动手、爱沉默 | 决定评估方式 |
| 情绪触发点 | 被催促、比较、重复练习 | 决定风险规避策略 |

---

## 四、教材知识图谱层

用于明确“孩子学到哪里、知识之间如何关联”。

### 1. 基础结构

```text
学科 → 单元 → 知识点 → 能力点 → 题型/任务
```

示例：

```text
数学
└── 分数
    └── 分数加减法
        ├── 同分母加减
        ├── 异分母通分
        ├── 带分数转化
        └── 应用题建模
```

### 2. 知识点关系

| 关系类型 | 说明 | 示例 |
|---|---|---|
| 前置依赖 | 学这个之前必须会什么 | 异分母加减依赖最小公倍数 |
| 横向关联 | 不同知识点之间的连接 | 分数、小数、比例互化 |
| 易错迁移 | 一个错误会影响哪些后续内容 | 通分不稳影响分式、比例计算 |
| 教材映射 | 对应教材章节、页码、课标要求 | 人教版五年级下册第 4 单元 |
| 能力映射 | 对应计算、理解、推理、表达等能力 | 应用题对应数量关系建模 |

### 3. 知识点数据结构

```json
{

  "subject": "数学",

  "textbook_version": "人教版",
  "prerequisites": [
    "最小公倍数",
    "通分",
    "同分母分数加减"
  ],
  "difficulty": 3,
  "importance": 5,
  "common_misconceptions": [
    "分母直接相加",
    "通分后只改分母不改分子",
    "约分遗漏"
  ],
  "assessment_methods": [
    "选择题",
    "计算题",
    "口述解题过程",
    "生活应用题"
  ]
}
```

## 五、学习证据层

这是知识库最关键的一层，用来记录孩子真实学习过程。

### 1. 数据来源

| 数据类型 | 示例 |
|---|---|
| 教材数据 | 章节、例题、课后题、知识点讲解 |
| 练习数据 | 作业、错题、口算、应用题 |
| 测验数据 | 单元测、周测、阶段测 |
| 视频学习数据 | 看课时长、暂停、回看、跳过、互动回答 |
| 语音片段 | 口述解题、背诵、朗读、随机抽查 |
| 图像/手写 | 草稿纸、错题拍照、书写质量 |
| 生活片段 | 生活中的数学、表达、观察、习惯行为 |
| 家长/老师反馈 | 情绪、习惯、课堂表现、作业态度 |

### 3. 每道错题至少记录四件事

| 问题 | 示例 |
|---|---|
| 错在哪里 | 分母直接相加 |
| 错因类型 | 概念误解 |
| 是否稳定错误 | 连续多次出现，说明不是粗心 |
| 影响哪些后续知识 | 分数四则运算、比例、方程应用题 |

## 六、掌握度模型层

掌握度不能只用一个分数表示，应拆成多个维度。

### 1. 掌握度维度

| 维度 | 含义 |
|---|---|
| 理解度 | 是否明白概念 |
| 熟练度 | 做题速度和稳定性 |
| 迁移度 | 能否换场景应用 |
| 表达度 | 能否讲清楚为什么 |
| 保持度 | 过几天是否还记得 |
| 易错风险 | 是否存在稳定错误模式 |
| 情绪阻抗 | 是否对该知识点排斥、焦虑、逃避 |

### 2. 掌握度数据结构

```json
{
  "student_id": "stu_001",
  "knowledge_point_id": "math_fraction_addition_unlike_denominator",
  "mastery": {
    "conceptual_understanding": 0.45,
    "procedural_fluency": 0.52,
    "application_transfer": 0.30,
    "verbal_explanation": 0.40,
    "retention": 0.55,
    "error_risk": 0.78,
    "emotion_resistance": 0.25
  },
  "status": "fragile",
  "last_assessed_at": "2026-06-03",
  "evidence_count": 18,
  "recent_trend": "declining",
  "recommended_next_action": "回到通分概念，用图形化方式重建理解"
}
```

### 3. 掌握状态分级

| 状态 | 含义 | 策略 |
|---|---|---|
| 未接触 | 没学过 | 正常引入 |
| 初识 | 能听懂但不能独立做 | 讲解 + 示例 |
| 脆弱 | 简单题会，换法就错 | 变式练习 |
| 稳定 | 常规题稳定正确 | 间隔复习 |
| 熟练 | 快速准确 | 减少重复 |
| 可迁移 | 能解释、应用、举例 | 拓展挑战 |

## 七、错因诊断层

错因诊断决定 Agent 是“家教”还是“刷题机”。

### 1. 错因分类体系

| 一级错因 | 二级错因 | 示例 |
|---|---|---|
| 概念误解 | 定义错、关系错、边界错 | 认为分母可以直接相加 |
| 程序错误 | 步骤遗漏、顺序错误 | 通分后忘记约分 |
| 计算错误 | 口算、抄写、符号 | 7×5 算成 30 |
| 审题错误 | 条件漏看、单位混淆 | 把“剩下”看成“一共” |
| 表达错误 | 会做但说不清 | 应用题答句缺单位 |
| 策略错误 | 方法低效、不会建模 | 复杂题只靠试数 |
| 习惯问题 | 草稿混乱、不检查 | 竖式不对齐 |
| 情绪问题 | 急躁、逃避、畏难 | 难题跳过不读题 |
| 注意力问题 | 漏字、跳步 | 把 15 看成 51 |

### 2. 错因与干预动作

| 错因 | 不该做 | 应该做 |
|---|---|---|
| 概念误解 | 继续加题量 | 回到概念模型、图示、反例 |
| 计算错误 | 讲一遍概念 | 高频短练、口算自动化 |
| 审题错误 | 只判错 | 训练圈关键词、复述题意 |
| 习惯问题 | 讲新课 | 建立检查清单 |
| 情绪问题 | 加压 | 降难度、增强可控感 |

## 八、成长规划层

成长规划不只是学习计划，而是多条线并行。

### 1. 五条规划线

| 规划线 | 内容 |
|---|---|
| 知识线 | 章节、知识点、前置补洞 |
| 能力线 | 计算、阅读理解、表达、推理、专注 |
| 习惯线 | 预习、复盘、错题整理、检查 |
| 情绪线 | 畏难、拖延、挫败恢复 |
| 兴趣线 | 项目式学习、生活应用、探索任务 |

## 九、智能行动层

Agent 应基于知识库做出具体行动，而不是只生成报告。

### 1. 核心能力

| 能力 | 输入 | 输出 |
|---|---|---|
| 智能出题 | 知识点掌握度、错因、教材进度 | 个性化题目 |
| 智能讲解 | 错题、学生表达、性格 | 适合孩子的讲解 |
| 自适应练习 | 最近表现、疲劳度 | 调整难度和题量 |
| 随机抽查 | 保持度、遗忘曲线 | 语音/选择/小任务抽查 |
| 习惯纠正 | 作业过程、草稿图像、家长反馈 | 具体习惯建议 |
| 成长报告 | 周期数据 | 家长/孩子/老师不同版本报告 |
| 劳逸结合 | 情绪、专注、时间 | 插入休息、运动、游戏化任务 |

### 2. 行动决策示例

```json
{
  "trigger": "连续两次异分母分数加法错误",
  "diagnosis": "概念误解，不是粗心",
  "student_traits": {
    "frustration_tolerance": "medium_low",
    "likes_visual_tasks": true
  },
  "next_action": {
    "type": "micro_lesson",
    "duration_minutes": 6,
    "method": "用披萨图解释为什么分母不能直接相加",
    "follow_up": "出 3 道图形化题 + 2 道计算题",
    "avoid": [
      "直接说你又错了",
      "连续刷 20 道同类题"
    ]
  }
}
```

## 十一、推荐落地路线

### 阶段 1：知识图谱

建立教材知识结构：

- 学科
- 年级
- 教材版本
- 章节
- 知识点
- 前置依赖
- 常见错因
- 题型映射

### 阶段 2：学习证据

先接入结构化数据：

- 题目
- 学生答案
- 标准答案
- 对错结果
- 解题步骤
- 错因标签

### 阶段 3：掌握度模型

建立知识点状态：

- 理解度
- 熟练度
- 迁移度
- 保持度
- 表达度
- 易错风险

### 阶段 4：错因诊断

区分不同错误来源：

- 概念误解
- 步骤错误
- 计算错误
- 审题错误
- 习惯问题
- 情绪问题

### 阶段 5：智能行动

根据诊断结果输出：

- 下一道题
- 下一次讲解
- 下一次复习
- 下一次抽查
- 下一周计划

### 阶段 6：多模态扩展

再逐步接入：

- 语音抽查
- 手写识别
- 视频学习行为
- 生活观察片段
- 家长/老师反馈

### 阶段 7：成长规划

形成阶段性成长计划：

- 周计划
- 月计划
- 学科目标
- 能力目标
- 习惯目标
- 情绪支持
- 兴趣拓展

## 十二、设计原则

1. **证据优先**  
   所有判断都要来自学习证据，而不是主观印象。

2. **动态更新**  
   学生画像、掌握度、错因模式都要随新证据更新。

3. **可解释**  
   每个推荐动作都要能说明依据。

4. **可行动**  
   知识库不是为了展示数据，而是为了决定下一步做什么。

5. **不只看对错**  
   要看过程、错因、情绪、习惯和迁移能力。

6. **先单学科跑通**  
   不要一开始就做全科、多模态、复杂规划。

7. **保护隐私**  
   语音、图像、生活片段属于高敏数据，要有明确授权、最小采集和可删除机制。

---

## 十三、一句话总结

学生知识库的核心不是“存了多少资料”，而是能否持续、准确地判断：

> 孩子当前在哪里，卡在哪里，为什么卡住，下一步怎么帮他走过去。
