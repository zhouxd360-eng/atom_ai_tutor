# 家庭导师智能Agent - 技术方案文档 V1.0

## 1. 系统概述
本项目是基于本地大模型 + RAG 检索 + 多模态处理的 K12 智能辅导系统，采用模块化架构，支持本地私有化部署。

## 2. 技术栈
- 后端：FastAPI + Uvicorn
- 前端：Gradio
- 大模型：GGUF 本地量化模型
- 多模态：PaddleOCR + FunASR + 视频解析
- 数据库：SQLite + 向量数据库
- 部署：单机本地部署
